# IoT Smart Gas Leak Detector

An IoT-based smart gas detection system that monitors air quality using an MQ135 sensor, provides instant alerts, and logs data to the cloud.

## 🛠️ Tech Stack & Hardware
* Microcontroller: Arduino Uno
* Sensor: MQ135 Gas Sensor
* Outputs: Buzzer & LED Alarm
* Simulation: Tinkercad
* Enclosure: Custom 3D Printed Casing

## ✨ Features
* Real-time toxic gas detection and instant alarm.
* Cloud integration for data storage.
* Edge AI analysis.

## 🚀 Future Enhancements
* Predictive gas leak analysis.
